## ReachX User Guide

A Python/Qt application for reviewing, processing, and analyzing video camera and other data recorded during reach 
behavior experiments in the Christie lab at UC Anschutz.
___
***ReachX*** replaces the "Video Explorer" and "Reach Curator" components of the `reach-training` Python 
[application suite](https://github.com/Cerebellum-Lab/reach-training). Among its key design goals:
 - A modern, more responsive user interface based on `PySide6` and `PyQtGraph` frameworks.
 - Eliminate dependence on the very large `DeepLabCut` library for machine learning. Training and applying object 
detection models now solely relies on the `TensorFlow` library.
 - Eliminate reliance on multiple, user-maintained configuration files and simplify installation by using a standard
Python wheel file.
 - Additional support for analyzing, plotting, and comparing hand/pellet trajectories during a session's reach
segments.

### Chapters
 - *Overview*: A brief introduction to the program.
 - *Fixed/Legacy-Cam Support*: Outlines the key
differences between the new fixed-cam rig and the older legacy-cam rig. ***ReachX*** supports analysis of experiment
sessions recorded on either rig.
 - *Configuration*: Describes how application configuration works in ***ReachX***, along with the user workspace 
concept.
 - *User Interface*: Describes the user-customizable layout of ReachX, along with an introduction to each of its
individual "views".
 - *Reviewing Video*: Explains how to load a session for review, use the various controls on the **Main Cameras View** 
to playback the current session's video streams, and jump back and forth to key events in the session timeline.
 - *Modeling*: A step-by-step guide on how to create and train a ***ReachX*** body part detection model, then use a
trained model iteration to analyze sessions and perform automated reach segmentation.
 - *Curating Reaches*: Describes how to use the `TimeLine` widget to add, edit and delete curated reaches for the
current loaded session.
 - *Trajectory Analysis*: Layout, features, and usage instructions for the **Trajectory Analysis** Window.
 - *Session Files*: A description of the folder contents for a fully analyzed session, with some code snippets to help
you load and use certain files generated by ***ReachX***.
 - *Keyboard Shortcuts*: Brief summary of all defined keyboard accelerators in ***ReachX***, both global shortcuts 
(always active) as well as widget-specific "hot keys" that are active only when the mouse cursor is within that widget.
