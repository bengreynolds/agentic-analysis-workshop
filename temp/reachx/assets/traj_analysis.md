## Trajectory Analysis

The **Trajectory Analysis** view (`View | Trajectory Analysis`) offers interactive plotting of
reach trajectories for the current loaded session. Unlike other **_ReachX_** views, it is housed in its own dedicated 
top-level application window. Key capabilities:

- Choose to display the curated or scored set of reaches, with per-reach selection and filtering.
- Default 2D Y/Z plotting with optional 3D view (when OpenGL support is available). 
- Flexible control over the appearance of (right) hand and/or pellet trajectories - particularly in the 2D view.
- **Live** mode to sync plotting with the current frame in the main app, showing only the reach containing that frame
  and a tracer to the current position.
- Export figure to PNG/SVG/PDF/EPS.
- Export the playback of hand (and pellet, optionally) trajectory during the "focus segment" to MP4.
